# DISPUTE Web V1
Low-cost marketing website for the live DISPUTE Android app.

## Stack
Next.js + TypeScript + plain CSS. No paid builder, database, authentication, web billing, Shopify, Lovable, or Codex dependency.

## Run
npm install
npm run dev

## Deploy
Push to GitHub and import the repository into Vercel.

## Important
The Google Play URL is set to package `sg.claimproof.mobile`. Verify the public Play listing URL before production deployment.
Privacy / Terms / Contact are currently footer placeholders and should be connected to the app's approved policy pages before production.
